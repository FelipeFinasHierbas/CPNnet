# CPNnet Security — datos de la empresa

Fuente: catálogo "Catálogo de Ciberseguridad" (PDF). Completar con el sitio oficial (www.cpnnetsecurity.com) cuando sea accesible.

## Quiénes son
- CPNnet Security es un **socio estratégico de ciberseguridad para Latinoamérica**: "no es solo un distribuidor". Acompaña a cada organización desde la identificación de riesgos y necesidades hasta la selección, implementación y evolución de las soluciones.
- Más de **18 años** acompañando a canales, integradores y fabricantes.
- Presencia regional: **Colombia, Perú y toda Latinoamérica**.
- Aportes a sus partners: conocimiento técnico (soporte especializado por marca), generación de demanda (herramientas y recursos para abrir oportunidades con clientes finales) y presencia regional.
- Llamado a la acción del catálogo: "Contacta a tu ejecutivo CPNnet".

## Cómo organizan el portafolio
3 dominios y 6 categorías. Detalle de marcas en `brands.json`.

| Dominio | Categoría | Marcas de primer orden | Cross-selling |
|---|---|---|---|
| Protección | Identity & Access Security | Segura, OneSpan | Sophos XDR/MDR |
| Protección | Network & Hybrid Infrastructure Security | Sophos Network, SonicWall, Faronics | Segura, Cymulate |
| Protección | Application Security & DevSecOps | Aikido Security | Segura, OneSpan, Cymulate |
| Gestión de Riesgo | Exposure Management & Continuous Validation | Vicarius, Cymulate, Action1, VectoraIQ | Aikido Security |
| Gestión de Riesgo | Data Security, Governance & Insider Risk | Kriptos, Safetica | Segura, Sophos XDR/MDR |
| Operaciones de Seguridad | Security Operations & XDR | Sophos XDR/MDR, Sophos Taegis, Seceon | Vicarius, Segura, Stellar Cyber, Action1 |

Además: **Soluciones Especializadas** (marcas de cross-selling): Stellar Cyber, Veracode, Ridge Security, Appgate, GoTo, LastPass, AlgoSec, Hacknoid, Ironchip, Teramind.

## Lo que el catálogo NO dice (el bot no debe inventarlo)
- Precios, descuentos, márgenes, plazos de entrega, SLAs.
- Condiciones de partner / programa de canal.
- Datos de contacto (teléfono, correo, WhatsApp, direcciones, nombres de ejecutivos).
- Certificaciones, casos de éxito, nombres de clientes.
- Para varias marcas, el modelo de cotización lo valida CPNnet con el fabricante (VectoraIQ lo dice explícitamente).
