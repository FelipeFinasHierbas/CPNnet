Integración con el CRM

Tres formas de llevar los leads al CRM de CPNnet. Este plugin nunca escribe en la base de datos del CRM.

1 · Exportar a CSV

Desde Leads, el botón «Exportar CSV» descarga los leads con los filtros aplicados. Se abre directo en Excel y la mayoría de los CRM lo importan.

2 · API de consulta (token)

Estado: Activa token terminado en …a41f

Ejemplos

curl -H "Authorization: Bearer TU_TOKEN" \
  "https://www.cpnnetsecurity.com/wp-json/cpnnet-asistente/v1/leads?exported=0&limit=50"

# Marcar como ya importados en el CRM
curl -X POST -H "Authorization: Bearer TU_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"ids":["UUID1","UUID2"]}' \
  "https://www.cpnnetsecurity.com/wp-json/cpnnet-asistente/v1/leads/mark-exported"

Filtros de /leads: status, perfil, exported (0/1), updated_since (ISO 8601), from/to (AAAA-MM-DD), limit (máx. 200), page, include=conversation. Detalle de un lead: /leads/{id}.

3 · Webhook (aviso inmediato al CRM)

Cuando entra un lead, el plugin envía un POST JSON a la URL que indiques (por ejemplo, un script del CRM en el mismo hosting). Si responde con éxito (2xx), el lead se marca como exportado.

Cómo bajar el costo

  • Cambiar a un modelo más económico (pestaña General).
  • Acortar el contenido: cada marca, y las reglas, se envían en cada mensaje.
  • Mantener el esfuerzo de razonamiento en «Bajo».
  • Fijar el tope mensual y créditos prepagados en la consola de Anthropic.
